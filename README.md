# MailGuard AI

AI-powered Spam and Phishing Message Detection System.

## Technologies
- Python
- Flask
- Machine Learning
- Naive Bayes
- TF-IDF
- Google Gemini API
- SQLite
- HTML
- CSS
- JavaScript

## Run the project

Install packages:

pip install -r requirements.txt

Train the model:

python train_model.py

Run the application:

python app.py

Open:

http://127.0.0.1:5000

## Features
- Spam classification
- Optional Gemini AI review
- Risk assessment
- Suspicious keyword detection
- Analysis history
- Dashboard statistics

## Dataset
The included dataset is a small demonstration dataset.
